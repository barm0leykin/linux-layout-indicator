# Релизный чек-лист

Порядок выпуска версии. Пункты отмечаются только после фактической проверки.

## Перед релизом

- [ ] `cargo fmt --check` — чисто
- [ ] `cargo clippy --all-targets -- -D warnings` — чисто
- [ ] `cargo test` — все тесты проходят
- [ ] `cargo build --release` — собирается
- [ ] Версия поднята в `Cargo.toml`
- [ ] `CHANGELOG.md` обновлён (если ведётся)

## Проверки на живой системе

- [ ] Демон запускается, бейдж появляется при `Alt+Shift`
- [ ] Второй экземпляр не стартует
- [ ] Клик по бейджу проходит сквозь
- [ ] Окно отсутствует в `Alt+Tab` и на панели задач
- [ ] В полноэкранном приложении бейдж не показывается
- [ ] `--doctor` отрабатывает без ошибок
- [ ] `--caret-probe` ведёт себя предсказуемо (в т.ч. при выключенной a11y)
- [ ] Hot reload конфига применяется
- [ ] Иконка в трее появляется; клик ставит на паузу, повторный — возвращает
- [ ] Меню трея: «Приостановить/Включить», «Открыть конфиг», «Выход» — работают
- [ ] 8-часовая сессия: RSS не растёт, CPU в простое ≈ 0

## Приватность (обязательно)

- [ ] Нет сетевых соединений:
      `strace -f -e trace=network ./target/release/layout-indicator`
      → только `AF_UNIX` (X11 и D-Bus)
- [ ] В логах нет содержимого полей, символов и заголовков окон
- [ ] `grep -ri "reqwest\|hyper\|ureq\|curl" Cargo.lock` — пусто
- [ ] README: раздел «Приватность» актуален

## Артефакты

- [ ] `cargo deb` → `.deb` собирается, содержимое проверено `dpkg-deb -c`
- [ ] `packaging/PKGBUILD` актуален (после публикации репозитория)
- [ ] Тег `vX.Y.Z` в git
- [ ] Release notes с известными ограничениями

## Известные ограничения (проверить, что описаны честно)

- [ ] Только X11; Wayland — отдельный этап
- [ ] `positioning: caret` требует включённой accessibility и перезапуска приложений
- [ ] `show_on_focus` срабатывает на смену окна, а не отдельного поля
- [ ] Прозрачность требует композитора
